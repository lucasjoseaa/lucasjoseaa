## 👨‍💻 Sobre mim

**QA Engineer Jr.** com background em desenvolvimento de software, focado em testes manuais e automatizados de aplicações **web, mobile e APIs**, do levantamento de requisitos à execução no pipeline de CI/CD.

| Área | Atuação | Ferramentas |
|---|---|---|
| 📋 **Planejamento** | Análise de requisitos, técnicas de design de teste, planos e casos de teste com rastreabilidade | TestRail, Jira |
| 🧭 **Metodologias** | Escrita de critérios de aceite e cenários em Gherkin, com testes integrados ao fluxo ágil | Scrum, Kanban, BDD/Gherkin |
| 🔍 **Testes manuais** | Funcionais, exploratórios, regressão, smoke, integração e usabilidade em web e mobile | Chrome DevTools, Android Studio |
| ⚙️ **Automação E2E** | Cenários positivos, negativos e de borda com Page Object Model e relatórios HTML | Playwright, Cypress, Selenium, Pytest |
| 💻 **Linguagens** | Escrita de scripts de automação e testes em JS/TS e Python, com base em desenvolvimento em PHP e C++ | TypeScript, JavaScript, Python, PHP, C++ |
| 🔌 **API** | Validação de endpoints, status codes, payloads JSON/XML e integração frontend-backend | Postman, Bruno |
| 🗄️ **Dados** | Consultas SQL para validar a persistência e a consistência dos dados | PostgreSQL, MariaDB, DBeaver |
| 🔄 **CI/CD** | Execução de suítes no pipeline, análise de logs e triagem de regressões e testes instáveis | GitHub Actions, Git |
| 🐛 **Defeitos** | Registro, priorização e acompanhamento de bugs pelo ciclo de vida completo | Jira |
| 🤖 **IA aplicada** | Geração de casos, dados e scripts de teste, sempre com revisão crítica | Claude, Copilot, ChatGPT |
